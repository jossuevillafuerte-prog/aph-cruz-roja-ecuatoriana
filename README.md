# APH · Cruz Roja Ecuatoriana

Aplicación de registro de atención prehospitalaria en Laravel y MySQL, con acceso provincial y administración nacional.

El código vigente está en [`aph-laravel/`](aph-laravel/). Incluye atenciones, recursos, usuarios, perfiles, impresión y un dashboard con mapas y filtros estadísticos.

La política vigente de acceso está en [Roles y activación](aph-laravel/docs/Roles-y-activacion.md). Los documentos anteriores se conservan como antecedentes; las decisiones más recientes sustituyen las referencias históricas a segundo factor.

Este repositorio contiene código y recursos de la aplicación. No incluye credenciales, fichas de pacientes, bases de datos, matrices originales, registros de ejecución ni dependencias instaladas. `.env.example` es una plantilla sin secretos.

La publicación en GitHub no despliega la aplicación. El alojamiento, dominio HTTPS y envío institucional de correo siguen pendientes de configuración. La importación de datos y el aprovisionamiento de cuentas requieren un procedimiento separado con acceso autorizado a esos datos.
